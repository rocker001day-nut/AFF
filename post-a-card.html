01 · สร้างการ์ดภาพ

อัปภาพแล้วใส่ URL ที่ต้องการให้คนไปเมื่อกดภาพ

หลังเข้าสู่ระบบสามารถสร้างการ์ดได้ แม้ยังไม่เลือกเพจ
สร้างการ์ดสำเร็จ

กดคัดลอก แล้ววางข้อความพร้อมลิงก์ในช่องสร้างโพสต์ Facebook เพื่อตรวจภาพตัวอย่างก่อนเผยแพร่

เปิด Facebook
Facebook แสดงเป็นพรีวิวลิงก์ที่คลิกภาพแล้วไป URL ปลายทาง รูปและปุ่มขึ้นอยู่กับการแสดงผลของ Facebook

02 · โพสต์หลายเพจอัตโนมัติ (เมื่อตั้งค่าการเชื่อมแล้ว)

เชื่อมเพจของคุณ แล้วเลือกหลายเพจเพื่อโพสต์ภาพและข้อความเดียวกันตามดีเลย์ที่ตั้งไว้

กำลังตรวจวิธีเชื่อมต่อ…
เมื่อเชื่อม Facebook ระบบจะใช้บัญชีที่ล็อกอินในเบราว์เซอร์ส่วนขยายตรวจสถานะ (ไม่จำเป็น)
ขั้นตอนแรกสำหรับเจ้าของเว็บ: เปิดการเชื่อม Facebook

เจ้าของเว็บสมัคร Upload-Post แล้วนำ API key ของบริการมาตั้งค่าครั้งเดียว จากนั้นผู้ใช้ที่เข้าสู่ระบบกดเชื่อม Facebook เพื่ออนุญาตและเลือกเพจของตัวเองได้ โดยไม่ต้องกรอก App ID, App Secret หรือ Page token · บริการมีโควตาและแผนตามบัญชีที่สมัคร

ทางเลือก: ใช้ Meta App ของ AFF เอง

เจ้าของเว็บสร้างแอปที่ Meta for Developers แล้วนำ App ID กับ App Secret มาตั้งค่าครั้งเดียว ช่องนี้ไม่ใช่ Page token

ตั้งค่า Valid OAuth Redirect URI เป็น https://txbsrtunejnqaheuohck.supabase.co/functions/v1/facebook-publisher?action=callback และขอสิทธิ์ pages_show_list, pages_read_engagement, pages_manage_posts
