# AFF Facebook Pages (ทดลอง)

ส่วนขยายนี้ช่วยหน้า `https://aff-lyart.vercel.app/facebook-pages` อ่านรายชื่อเพจที่ **แสดงบนหน้า Facebook Pages ใน Chrome เครื่องเดียวกัน** ไม่มีการส่งค่าคุกกี้ Facebook ไปที่ AFF

## ติดตั้ง

1. ดาวน์โหลดไฟล์ ZIP ของส่วนขยายจากหน้า AFF แล้วแตกไฟล์จนเห็น `manifest.json` ในโฟลเดอร์ `aff-facebook-extension`
2. เปิด `chrome://extensions` → เปิด **Developer mode** → **Load unpacked** → เลือกโฟลเดอร์ `aff-facebook-extension` ที่แตกไฟล์แล้ว (อย่าเลือก ZIP)
3. ล็อกอิน Facebook ใน Chrome เครื่องนี้ เปิดหน้า AFF `/facebook-pages` ใหม่ แล้วกด **ค้นหาเพจจาก Chrome**

ส่วนขยายจะเปิดหน้า Facebook Pages เป็นแท็บเบื้องหลังชั่วคราวเพื่ออ่านชื่อ/ID ที่แสดงบนหน้าเว็บ การพบลิงก์เพจยังไม่ยืนยันสิทธิ์โพสต์ และรูปแบบหน้า Facebook อาจเปลี่ยนได้ โปรดตรวจเพจที่แสดงก่อนใช้งาน ไม่มีการโพสต์หรือใช้ API ลับในเวอร์ชันนี้

## สิทธิ์และข้อมูล

- `cookies`: ตรวจว่ามีการล็อกอิน Facebook โดยดูว่าคุกกี้ `c_user` มีอยู่หรือไม่ ไม่อ่านค่าไปส่งให้เว็บ
- `tabs`, `scripting`: เปิดหน้า Facebook Pages ชั่วคราวและอ่านชื่อ/ID เพจจากหน้าเว็บ
- เฉพาะหน้า AFF ที่ตรง origin จึงสั่งให้ส่วนขยายทำงานได้
- ไม่บันทึกหรือส่งคุกกี้/โทเค็น/HTML ของ Facebook ไปเซิร์ฟเวอร์ AFF

หากหน้า Facebook ไม่แสดงลิงก์เพจรูปแบบที่ส่วนขยายรู้จัก ระบบจะแจ้งว่าไม่พบเพจ อย่าตีความว่าไม่มีสิทธิ์ดูแลเพจ
