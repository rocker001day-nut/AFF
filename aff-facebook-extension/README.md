# AFF Facebook Check

ส่วนขยาย Chrome แบบ Manifest V3 สำหรับตรวจว่า Chrome โปรไฟล์นี้ล็อกอิน Facebook อยู่หรือไม่ และแสดงสถานะในหน้า **โพสต์ภาพ + ลิงก์** ของ AFF

## ติดตั้งเพื่อทดสอบ

1. แตก ZIP แล้วเปิด `chrome://extensions` ใน Chrome
2. เปิด **Developer mode** และกด **Load unpacked** เลือกโฟลเดอร์ `aff-facebook-extension`
3. เปิด Facebook และล็อกอินใน Chrome โปรไฟล์เดียวกัน
4. รีเฟรช `https://aff-lyart.vercel.app/post-a-card` สถานะส่วนขยายจะปรากฏในหัวข้อโพสต์หลายเพจ
5. กดไอคอนส่วนขยาย แล้วกด **เชื่อม Facebook และดึงเพจ** ระบบจะเปิด AFF และเริ่ม Facebook Login ให้อัตโนมัติเมื่อเจ้าของเว็บตั้งค่าการเชื่อมเรียบร้อยแล้ว

ส่วนขยายอ่านเฉพาะการมีอยู่ของคุกกี้ `c_user` เพื่อส่งค่า `true/false` ให้หน้า AFF ไม่ส่งค่าคุกกี้หรือ access token ออกจากเครื่อง ไม่ใช้ debugger หรือเปลี่ยน header ของเว็บอื่น การมีคุกกี้ไม่ได้ยืนยันว่าเพจพร้อมโพสต์

การดึงรายชื่อเพจและโพสต์จริงยังต้องเชื่อมผ่าน Facebook Login ที่มี Meta App และสิทธิ์ Pages API หรือบริการ OAuth ที่เจ้าของเว็บตั้งค่าไว้หนึ่งครั้ง จากนั้นผู้ใช้อนุญาตเพจในหน้า Facebook ตามปกติ

หน้าใช้งานสำหรับทุกคน: https://aff-lyart.vercel.app/post-a-card
