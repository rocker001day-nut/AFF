# AFF Edit Post Assistant สำหรับ Chrome

ส่วนขยายนี้ทำงานร่วมกับหน้า [คิวแก้ลิงก์ AFF](https://aff-lyart.vercel.app/#editpost) เพื่อเปิดโพสต์ Facebook และช่วยแทนลิงก์ Shopee เก่าใน **ช่องแก้ไขข้อความที่เปิดอยู่** ให้เป็นลิงก์ใหม่ โดยผู้ใช้ตรวจเพจ/ข้อความและกดบันทึกบน Facebook เอง

## ติดตั้ง

1. ดาวน์โหลด `aff-edit-post-extension.zip` จากหน้า AFF แล้ว **แตกไฟล์ ZIP**
2. เปิด `chrome://extensions` ใน Chrome → เปิด **โหมดนักพัฒนาซอฟต์แวร์ (Developer mode)**
3. กด **โหลดส่วนขยายที่แตกไฟล์แล้ว (Load unpacked)** → เลือกโฟลเดอร์ `aff-edit-post-extension` ที่มี `manifest.json` อยู่ข้างใน อย่าเลือกไฟล์ ZIP
4. รีเฟรชหน้า AFF และล็อกอิน Facebook ใน Chrome เครื่องเดียวกัน

## ใช้งาน

1. เปิด `https://aff-lyart.vercel.app/#editpost` แล้วล็อกอิน AFF
2. เปิด Excel งานหรือไฟล์สำรอง .affedit จากหน้านี้ กรอกลิงก์ Shopee ใหม่ และตรวจว่าชี้สินค้าถูกต้อง
3. กด **ให้ส่วนขยายช่วยแก้** ในรายการที่เลือก Chrome จะเปิดโพสต์บน Facebook
4. ตรวจว่าเป็นเพจ/โพสต์ที่ต้องการ เปิดเมนู **แก้ไขโพสต์** หรือ **แก้ไขคอมเมนต์** บน Facebook และคลิกในช่องแก้ไข
5. กด **เติมลิงก์ใหม่ในช่องแก้ไข** แล้วอ่านข้อความก่อน/หลัง ตรวจสินค้า และกดบันทึกบน Facebook ด้วยตัวเอง
6. รีเฟรชโพสต์แล้วตรวจทั้งข้อความและคอมเมนต์ จากนั้นค่อยติ๊กสถานะบนเว็บ AFF

ส่วนขยายไม่ส่งคุกกี้ โทเค็น หรือ HTML ของ Facebook ไปที่เซิร์ฟเวอร์ AFF และไม่กดบันทึก Facebook อัตโนมัติ การแก้ลิงก์ที่ฝังในภาพ/พรีวิวลิงก์เดิมและ Ads ไม่รองรับด้วยตัวช่วยนี้ หาก Facebook เปลี่ยนหน้าแก้ไขหรือแสดงหลายช่อง ให้คัดลอกลิงก์จากแผงและวางด้วยตนเอง อย่าใช้สถานะหน้าเว็บเป็นหลักฐานว่าโพสต์ถูกบันทึกแล้วจนกว่าจะตรวจบน Facebook จริง
